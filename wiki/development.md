## Setup

Per `README.md` §"Installation" and `TECHNICAL.md` §"Dependency Installation"
— there is no `requirements.txt`:

```bash
git clone <repository_url> && cd frictionless-architect
pipx install poetry                                   # or: pip install --user poetry
poetry install --with dev,tests,lint,docs             # creates the venv + all groups
# then prefix commands with `poetry run`, or `poetry shell`
```

Dependency groups in `pyproject.toml`: `docs` (pdoc), `dev` (commitizen,
locust, pymarkdownlnt, pyarchimate, pyyaml, fastembed, numpy), `tests` (pytest
+ plugins, behave, httpx), `lint` (mypy, pyright, ruff, pysonar).

## Running the schema visualiser

The one runnable component (see [Visualizer Service](visualizer-service.md)):

```bash
# .env — point at Neo4j + sample data
FRICTIONLESS_ARCHITECT_NEO4J_URI=bolt://localhost:7687
FRICTIONLESS_ARCHITECT_NEO4J_USER=reader
FRICTIONLESS_ARCHITECT_NEO4J_PASSWORD=reader
FRICTIONLESS_ARCHITECT_SAMPLE_DATA_DIR=sample-data
FRICTIONLESS_ARCHITECT_CACHE_DIR=.cache/visualiser

poetry run uvicorn frictionless_architect.visualizer:app --reload --port 8100
# then open http://127.0.0.1:8100/schema-visualizer
```

(`README.md` §"Schema Visualiser". Neo4j is optional — with no `NEO4J_URI` the
service runs from sample data + cache alone.)
