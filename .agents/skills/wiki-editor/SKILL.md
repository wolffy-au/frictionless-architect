# Wiki Editor

Improves formatting and link hygiene on the generated `wiki/*.md` pages. This
is a structural tidy-up, not a re-synthesis — the `wiki-librarian` skill owns
what each page says and which sources it draws on; this skill only owns how a
page reads once generated.

Because pages are regenerated from `wiki/sources.yaml`, an edit here survives
only until the next rebuild of that page. Use this pass for a one-off polish
or right after a big run; systemic issues (a citation style you keep having
to fix) belong in the librarian skill instead.

## Steps

1. **Determine scope.** If the user named pages, use those. If run right
   after a librarian pass this session, default to the pages that pass
   regenerated. Otherwise default to all `wiki/*.md` except `index.md`.
2. **Read each target page in full**, plus `wiki/index.md`.
3. **Frontmatter completeness.** Each page should have `title`, `generated`,
   `generator`, and a `sources` list, followed by the "generated by
   wiki-librarian" note. Add a missing note; fix an obviously malformed
   block. Don't invent a `generated` date — if it's missing, flag it.
4. **Heading hierarchy.** One `#` H1 matching the title (or none, if the
   title lives only in frontmatter — match whichever the other pages use);
   no skipped levels (`##` then `####`); sentence-case headings consistent
   with the rest of the wiki.
5. **Citation hygiene.** Repo-file citations read `` (`path/to/file.md`
   §Heading) `` or `` (`path/to/file.py:40-58`) ``; URL citations read
   `` ([Title](url), retrieved YYYY-MM-DD) ``. Normalize drifted ones. If a
   cited path doesn't exist in the repo, flag it — don't guess a
   replacement.
6. **Internal links.** `[Title](other-name.md)` links between pages must
   resolve to a real page file. Fix a wrong slug; flag a link to a page that
   doesn't exist.
7. **Anchor slugs.** For a link into a heading on another page
   (`other.md#some-heading`), generate the slug the standard way
   (lowercase, spaces→`-`, punctuation dropped; an em dash `—` with its
   surrounding spaces collapses to a single `-`, not two) and verify it
   against the actual heading.
8. **Terminology consistency.** If a page switches between two names for the
   same thing (and the sources use one consistently), align to the source's
   term. If the sources themselves disagree, leave it and flag it.
9. **Formatting artifacts.** Stray blank lines, broken list nesting,
   duplicated headings, leftover merge residue.
10. **Build-log drift.** If a page's `sources` frontmatter no longer matches
    the topic's resolved sources, don't reconcile it here — flag it for a
    librarian rebuild.

## Must not

- Change a page's technical claims, add information not traceable to a cited
  source, or remove a citation.
- Edit `wiki/sources.yaml`, `wiki/.build-log.yaml`, `wiki/.cache/*`, or any
  repo file that serves as a source.
- Re-organize a page's sections in a way that changes what it covers — that's
  a librarian rebuild (or a `sources.yaml` change), not a copyedit.

Report back a short per-page summary of what changed, and flag anything you
couldn't safely fix (missing cited paths, source disagreements, frontmatter
drift) for a follow-up librarian run.
